# Diagnose

Use when a symptom is known but the causal boundary is not.

The GLM worker reproduces or inspects evidence, states one hypothesis, then runs
the cheapest discriminating check. Repeat only when evidence changes. Do not edit
production code. After two distinct failed hypotheses, or when architecture/blast
radius becomes material, route to the Sol teacher. Return root cause with file,
command, or runtime evidence; otherwise return the narrowest remaining unknown.
