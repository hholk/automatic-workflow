# Diagnose

Use when a symptom is known but the causal boundary is not.

The selected native worker reproduces or inspects evidence, states one
hypothesis, then runs the cheapest discriminating check. Repeat only when
evidence changes. Do not edit production code. After two distinct failed
hypotheses, hand back using the worker contract. Request a teacher only for
an unresolved material technical decision.
Return root cause with file, command, or runtime evidence, otherwise the
narrowest decisive unknown.
