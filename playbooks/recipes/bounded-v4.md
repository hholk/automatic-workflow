Give OBJECTIVE | SUCCESS | CONTEXT | PATHS | NON_GOALS | VERIFY. Include the
settled prerequisite outputs, original requirement sources and a concrete stop
condition. Use the resolved context budget as a target, not a reason to omit
decisive evidence. Prefer paths and relevant excerpts over entire histories.

Use the resolved tool-step budget cumulatively for the slice, including resumes
and teacher evidence gathering. Reserve room for integration and acceptance;
125 is the installed worker ceiling, not a target. Two failed hypotheses or a
repeated no-gain probe return to main. Main may authorize the existing one bounded
recovery within the remaining budget for a new discriminating probe. An outage
is an environment blocker and does not count as a technical hypothesis.

Return the worker contract concisely; include enough evidence to preserve every
unfinished item. DONE ends a turn, not acceptance. A user-forbidden verification
is explicitly NOT_RUN with its reason, never a fabricated exit code or PASS.
Main can take over a hard slice without exhausting repeated cheap-model attempts.
